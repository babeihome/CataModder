# CataclysmModder Navigation Guide

Welcome to the CataclysmModder project! This guide is intended to help new developers understand the project structure, locate key files and directories, and get started with the codebase.

The project is written in **C#** using the **.NET Framework** (specifically .NET 4.0 as mentioned in the UserGuide) and **Windows Forms** for the graphical user interface.

## Key Directories and Files

Below is a breakdown of the important directories and files within the CataclysmModder repository:

*   **`CataclysmModder/`**: This is the main directory containing all C# project files and source code for the application.
    *   **`CataclysmModder.sln`**: The Visual Studio Solution file. Open this file in Visual Studio to load the entire project, including all its settings and dependencies.
    *   **`CataclysmModder/CataclysmModder.csproj`**: The C# project file. It defines project-specific settings, such as the target .NET Framework version, dependencies on external libraries (if any), and a comprehensive list of all source code files included in the build process.
    *   **`CataclysmModder/Program.cs`**: Contains the `Main` static method, which serves as the initial entry point when the application is executed. Its primary responsibility is to initialize and run the main application window (`Form1`).
    *   **`CataclysmModder/Form1.cs`**: This file defines the main window (form) of the application. It's where the primary user interface is laid out and managed. `Form1` handles event logic for user interactions (e.g., button clicks, menu selections) and is responsible for coordinating the display of various data editing user controls.
    *   **`CataclysmModder/Form1.Designer.cs`**: This is an auto-generated companion file to `Form1.cs`. It contains the code that declares and initializes UI elements (buttons, text boxes, lists, etc.) and specifies their layout properties as designed in the Windows Forms visual designer. It's generally not recommended to edit this file manually; changes should be made using the Visual Studio designer for `Form1.cs`.
    *   **`CataclysmModder/Storage.cs`**: A critical static class that acts as the central hub for all data management operations. Its responsibilities are extensive and include:
        *   Loading JSON files from the game's data directories.
        *   Parsing the raw JSON text into internal, structured data representations (primarily using `List<BindingList<ItemDataWrapper>>`).
        *   Storing and providing access to this loaded data throughout the application.
        *   Saving any modifications made by the user back to the original JSON files.
        *   Defining an enumeration (`FileType`) to categorize different types of game data files (e.g., items, recipes, bionics).
        *   Holding `CataFile` objects, which describe properties for each `FileType`, such as the primary display key and the associated editing control.
        *   Managing and providing data sources (e.g., lists of available materials, skills) for UI controls, often used in dropdowns or autocomplete suggestions.
    *   **`CataclysmModder/ItemDataWrapper.cs`**: Defines a class that wraps individual JSON objects (e.g., a single item definition, a specific recipe). Each `ItemDataWrapper` instance holds its data primarily as a `Dictionary<string, object>`. It implements the `INotifyPropertyChanged` interface, which is crucial for data binding in Windows Forms, allowing UI elements to automatically refresh when the underlying data changes.
    *   **`CataclysmModder/*Values.cs` files** (e.g., `GunValues.cs`, `ArmorValues.cs`, `ComestibleValues.cs`, `RecipeControl.cs`, `MonsterValues.cs`, etc.): This collection of files represents custom `UserControl` classes. Each control is specifically designed to provide a user interface for editing a particular type of JSON object found in Cataclysm: Dark Days Ahead. For instance, `GunValues.cs` will have fields relevant to gun properties, while `ArmorValues.cs` will have fields for armor. These controls are dynamically loaded and displayed within `Form1` based on the type of file or item selected by the user.
        *   Each `*Values.cs` file has a corresponding **`*Values.Designer.cs`** file, which is auto-generated by the Windows Forms designer and contains the UI layout code for that specific user control.
    *   **`CataclysmModder/JsonSchema.cs`**: This class is responsible for serializing the internal data (dictionaries from `ItemDataWrapper` objects) back into well-formatted JSON strings. It uses schema definitions to ensure the output JSON adheres to the game's expected structure for each data type.
    *   **`CataclysmModder/schemas/`**: This directory contains text files (`.txt`) that define the JSON schemas. Examples include `items.txt`, `recipes.txt`, etc. These schemas are read by `JsonSchema.cs` to guide the JSON serialization process, ensuring that the output files have the correct structure and fields.
    *   **`CataclysmModder/Properties/`**: This standard C# project directory contains project-level metadata and resources.
        *   `AssemblyInfo.cs`: Contains assembly metadata like version, title, etc.
        *   `Resources.resx`: The main resource file for the project. It can store strings, images, icons, and other embedded resources. While schemas are primarily in the `schemas/` directory, it's possible some resources are embedded here.
        *   `Settings.settings`: For application-level settings.
    *   **`CataclysmModder/About.cs`**: Defines the "About" dialog window, which typically displays information about the application, its version, and authors.
    *   **`CataclysmModder/Options.cs`**: Defines the form used to configure application-specific options or settings.
    *   **`CataclysmModder/ExportItemsForm.cs`**: Defines a form that likely provides functionality for exporting game items or data in a specific format.

*   **`README.md`**: (Already exists) Located in the root of the repository. It provides a general overview of the CataclysmModder project, its purpose, and basic setup or usage information.
*   **`UserGuide.txt`**: (Already exists) Located in the root. This text file offers more detailed instructions on how to use the CataclysmModder application from an end-user's perspective.
*   **`ProjectOverview.md`**: (Newly created) Located in the root. This markdown file provides a high-level introduction to the project specifically for developers, outlining its goals and scope.
*   **`Architecture.md`**: (Newly created) Located in the root. This document details the software architecture of CataclysmModder, including descriptions of its main components and the general flow of data within the application.

This guide should provide a solid starting point for navigating the CataclysmModder codebase. Remember to explore the code starting with `Program.cs` and `Form1.cs` to understand the application's lifecycle and main interactions.
