# CataclysmModder Project Overview

## Main Purpose

CataclysmModder is a C# WinForms application designed for creating and editing JSON files for the game Cataclysm: Dark Days Ahead. It provides a user-friendly interface to manage various game data elements, simplifying the modding process.

## Target Game

The application specifically targets **Cataclysm: Dark Days Ahead (CDDA)**.

## Supported JSON File Types

CataclysmModder can handle a variety of JSON file types from the game, including:

*   **ITEMS:** Definitions for in-game items.
*   **BIONICS:** Information about bionic implants.
*   **ITEM_GROUPS:** Definitions for groups of items that can spawn together.
*   **MATERIALS:** Properties of different materials used in crafting and construction.
*   **MONSTER_GROUPS:** Definitions for groups of monsters.
*   **NAMES:** Lists of names used for characters, locations, etc.
*   **PROFESSIONS:** Starting professions for player characters.
*   **RECIPES:** Crafting recipes for items.
*   **SKILLS:** Definitions of player skills.
*   **SNIPPETS:** Reusable pieces of text or code for JSON entries.
*   **DREAMS:** Descriptions of character dreams.
*   **MUTATIONS:** Details about character mutations.
*   **MARTIAL_ARTS:** Definitions for martial arts styles and techniques.
*   **TECHNIQUES:** Specific combat techniques.
*   **VEHICLE_PARTS:** Definitions for parts used in vehicle construction.
*   **VEHICLES:** Definitions for complete vehicles.

This tool aims to streamline the modification of these core game files for modders.
